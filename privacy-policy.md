# Privacy Policy / プライバシーポリシー

Last updated: 2026-11-24

## English

**Application:** secretary (a personal, single-user tool)

secretary is a personal automation tool written and used by one person, the owner of the Google account that authorizes it. It is not offered to the public and has no other users.

**What it accesses.** With the owner's consent it reads Gmail messages using the read-only scope `https://www.googleapis.com/auth/gmail.readonly`. It also creates events in a dedicated calendar it owns, using the scope `https://www.googleapis.com/auth/calendar.app.created`.

**How the data is used.** Message headers and text are read to sort mail, to find deadlines and to prepare a daily summary for the owner. This processing runs on the owner's own computer with a locally hosted language model.

**Storage.** Short summaries, deadlines and sender/subject information are kept in a database on the owner's computer. Full message bodies and one-time authentication codes are not stored. OAuth tokens are kept in a local file on the owner's computer.

**Sharing.** The data is not sold, not shared with third parties, not used for advertising, and not used to train AI models. It is not transferred to other servers, except that for a limited comparison test, some message headers and the first part of the body of a few messages may be sent to Google's own Gemini API. Messages from financial institutions, government and other sensitive senders, and messages containing authentication codes, are never sent.

**Google API Services User Data Policy.** The use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

**Revoking access and deleting data.** The owner can revoke access at any time at https://myaccount.google.com/permissions and can delete the local database and token files from their computer.

## 日本語

**アプリ:** secretary（個人用・利用者は1人のツール）

secretary は、認可した Google アカウントの持ち主本人だけが作って使う、個人用の自動化ツールです。一般には公開しておらず、ほかの利用者はいません。

**アクセスするもの。** 持ち主の同意のもとで、読み取り専用の権限 `gmail.readonly` で Gmail のメールを読みます。また、このアプリが作った専用のカレンダーにだけ、権限 `calendar.app.created` で予定を作ります。

**使いみち。** メールの仕分け、締め切りの抽出、持ち主向けの毎日のまとめのために、件名・差出人・本文を読みます。処理は持ち主のコンピュータの中で、ローカルの言語モデルで行います。

**保存。** 短い要約・締め切り・差出人と件名は、持ち主のコンピュータのデータベースに残します。メール本文の全文と、ワンタイムの認証コードは保存しません。認可のトークンは、持ち主のコンピュータのファイルに保存します。

**共有。** データを販売・第三者へ提供・広告に利用・AI モデルの学習に使うことはありません。外部へは送りません。ただし、比較の検証として、一部のメールの件名・差出人と本文の冒頭だけを、Google 自身の Gemini API に送ることがあります。金融機関・官公庁などの差出人のメールと、認証コードを含むメールは、送りません。

**Google API サービスのユーザーデータポリシー。** Google API から受け取った情報の利用は、限定的使用の要件を含め、[Google API サービスのユーザーデータポリシー](https://developers.google.com/terms/api-services-user-data-policy)に従います。

**アクセスの取り消しとデータの削除。** 持ち主は、https://myaccount.google.com/permissions でいつでもアクセスを取り消せ、コンピュータ上のデータベースとトークンのファイルを削除できます。

**連絡先。** kouji.asahi@gmail.com
